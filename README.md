# Grover Podcast

The ultimate app to manage your favorite podcasts on Windows. Fast, lightweight, and native Windows application.

## 🌟 Features

- **Native Windows Performance**: Fast startup time (2 seconds) and lightweight memory usage (80 MB)
- **Automatic Podcast Management**: Download new episodes, add to playlists, and manage subscriptions
- **User-Friendly Interface**: Intuitive design with light and dark mode support
- **Cross-Platform Sync**: Sync subscriptions between devices through OneDrive
- **Xbox Compatible**: Runs seamlessly on Xbox devices

## 📊 Store Ratings

With more than 1,900 ratings, Grover is the best-rated podcast app on the Microsoft Store with a **4.5-star rating**.

## 🚀 Performance

- **Startup Time**: 2 seconds (vs 4s for iTunes, 6s for Spotify)
- **Memory Usage**: 80 MB RAM (vs 180MB for iTunes, 380MB for Spotify)
- **Native Windows**: Built specifically for Windows 10/11

## 🛠️ Development

This is a pure HTML/CSS/JavaScript project that can be built and minified for production.

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/matheus-inacio/grover-podcast.git
cd grover-podcast

# Install dependencies
npm install
```

### Build Commands

```bash
# Development server
npm run dev

# Build for production (minified)
npm run build

# Build with image optimization
npm run build:prod

# Serve production build
npm run serve
```

### Build Process

The build process includes:
- CSS minification using CleanCSS
- JavaScript minification using UglifyJS
- HTML processing to reference minified files
- Asset copying and optimization
- Image optimization (optional)
